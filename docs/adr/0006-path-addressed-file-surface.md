# 数据面是按路径的文件面

`#14` 把数据面定成「两个特殊目录（`/inputs`、`/outputs`）+ 目录同步」：进要一份声明清单、出要一份产物清单，由 Worker 在任务前后搬。`#20` 改成**按路径的文件面**：能力面上三个动词 **`ls` / `download` / `upload`**，按**工作区树内的路径**寻址，**与 Task 无关**——上传完就提交任务，要领什么自己去拿。三条旧结论随之作废：**`artifacts[]` 从 Task 信封里删掉**（`#7`）、**`/inputs` 与 `/outputs` 不再存在、也不作为约定保留**（`#16` 的两个挂载点一并取消）、**`POST …/inputs` 与 `artifact_get` 让位给文件面的端点**（`#18`）。

推翻的根据是**前提换了**，不是原结论错了：`#14`/`#15` 那套的论据是「我们禁出网 + 禁凭据入沙箱 ⇒ 数据只能平台自己搬 ⇒ 搬法收敛成两个目录」，而 `#16` 已经把「默认无网」明确否决。前提消失后，两个特殊目录只剩代价——**目录没有寻址粒度**，于是要配清单、配时机（每任务清空重填）、配结算与兜底（终态前收完、outbox）。按路径寻址让这些**不存在**，而不是变得更简单。先行形态一边倒：九家沙箱厂商 + 四个容器工具**没有一家**用资源句柄寻址普通文件，八家把「列目录」做成一等动词（Daytona 还明写 "without executing shell commands inside it"），**零家**有声明式产物——唯一同构先例是 Buildkite 的 `artifact_paths`，而 CI 需要它是因为那台机器会消失。证据：`docs/research/vendor-file-apis.md`。

传输沿用 `#14` 已定的管子，只是分工写明：**元数据走流**（`ls` 是控制层→Worker 在已拨通的出站流上的一次请求），**字节走对象存储 + 预签名 URL**，控制层不经手字节。因为我们的前提里平台碰不到沙箱（零监听端口、Worker 主动拨号），先行形态那条"平台 API 中转字节"的路（E2B 的路由进沙箱 envd 端口）对我们不成立。挂载取消之后，**文件面的命名空间就是工作区树**，白拿三件事：冷档工作区照常 `ls`/`download`/`upload`（不碰容器）、文件搬运与「沙箱活着」解耦、外层 agent 能在声明之前先看。

**Status**: accepted（`#20`）——文件面动词后来从三个变四个：`upload` 的完成信号由 `#25` 定下（见 `0008-upload-completion-signal.md`），形状与分工不变。

## Considered Options

- **保留 `/inputs`·`/outputs`，降级成约定**（不承载机制，只在 Skill 里教）：保住"数据区与代码区分开"的好处（`git status` 干净、输入只读）。否决理由：名字一旦进文档就有引力，而它的收益用一句话就能拿到——「要留下的东西放进工作区树」；平台不必认这两个名字。
- **保留 `artifacts[]` 作为承诺**（声明 glob、任务结束必收，Buildkite 形状）：给流水线调用方一个保证。否决理由：这个承诺买的是「沙箱随时会死」，而我们的工作区本来就跨任务与冷档持久，它在我们这里几乎不值钱；留着它就得把结算、终态次序、outbox 整套机件一起留下。
- **字节走「exec + 容器内 helper」**（Cloudflare `sandbox-shim` 的形状，也与 `#19`「同一份二进制的第二个入口」同构）：不经过平台存储，字节直接走 Worker 已拨通的流。否决理由：与 `#14`「字节不经控制层」相反，控制层会变成数据面的带宽瓶颈，对象的生命周期/断点/重试都要自己发明。留作整目录搬运时的升级路径（与 `#5` 的 STS 前缀会话同处）。
- **`ls` 走 Task**（沙箱里跑一条 `ls`）：零新机制，容器工具世界就这么干（`docker exec ls`）。否决理由：占任务串行位（`#7`/`#9`），看一眼目录要排在长任务后面；而且视图不同——Task 看的是**容器**，文件面看的是**工作区树**，混在一起会让"树是文件面唯一命名空间"这条规矩失效。

- **沿用 containerd 那一代的路径处理**（`strings.HasPrefix` 判前缀 + 越界时**静默 clamp 到 root**）：否决。moby 已经把整条解包链换成 `os.Root`（openat2 语义）+ `filepath.IsLocal` **拒绝**、不再在用户态改写路径，我们要照抄的是这一代。附带一条**规格级禁令**（2026-10-16 补，见 `docs/research/file-transfer-mechanics-and-path-safety.md`）：**本系统任何一处都不用 strip-then-compare**——它是那批路径穿越 CVE 的共同根因（GNU tar 的 `safer_name_suffix` 是**剥离**而非拒绝、node-tar 只剥一层 path root、`kubectl cp` 的 `stripPathShortcuts` + `isRelative` 修了六轮）。「先剥再比」看起来更宽容，实际是把判定权交给了改写后的字符串。

## Consequences

- **可复现性从"平台保证"退回"调用方自律"**：没有只读数据区（agent 可以改自己的输入），没有产物清单（平台不保证任何文件离开工作区）。这是本决定的主要代价，Skill 要写明。
- **"忘了拿"没有机制兜底**：冷档保留期是唯一的窗口。平台主动整树导出（Blaxel `archive/export` 形状）进 map 的 fog。
- 文件面是本项目新增的**宿主侧注入面**，三条死规矩进规格：调用方给的路径必须规范化且**落在工作区树内**（Worker 以宿主身份执行它）、**不跟随符号链接**（受信侧的沙箱能在树里造软链指向宿主别处）、**只处理普通文件**（FIFO/设备文件会让 `open` 挂住），外加体积上界。九家里只有 Cloudflare 提过路径限制，而且是**明确不管**（"Files does not restrict which paths it opens"）——负面证据，不是可抄的先例。
- 平台存储多出一类**中转对象**（上传暂存 / 下载暂存）：它们是**无主**的，寿命由保留期决定、不记账。契约见 `docs/adr/0007-staging-area-expiry.md`（`#23`）。
- `ls` **不占任务位**这条被定死了：任务串行（`#7`/`#9`）与「看一眼目录」不能互相排队。
- Skill 里那句可教的话从「产物先声明」换成「**要留下的东西放进工作区树**」——树是文件面唯一的命名空间，也是唯一跨任务与冷档活着的东西。
- **三条死规矩的实现细节**（2026-10-16 补，依据同上）：`os.Root` **并不禁止** bind mount、`/proc` 特殊文件与设备文件，`O_NOFOLLOW` 也只作用于最后一段 ⇒ 「只处理普通文件」必须自己判，且要 `Lstat` → `open` → `fstat` **复查 inode 一致**（防 TOCTOU）；`os.Root` 的方法集**没有 `CreateTemp`**，而 `rename` 的原子性只在**同一挂载点**内成立 ⇒ 临时名自己编、临时文件与目标同目录。
- **新缺口（本轮挖出）**：崩溃残留的**树内临时文件没有扫帚**——中转区有保留期兜底，树里没有。要么给临时文件一个可识别的命名前缀、在 Worker 启动对账时清掉，要么认下这点残留；不能靠「反正会被覆盖」。
- **Agent Sandbox 的 `/v1/files` 是一份可直接对着实现的语义清单**（`docs/research/container-sandbox-architecture.md` §8.4），四个动词应当逐条过一遍：`GET`/`HEAD`/`PUT`/`DELETE` 四方法、**原子写**（temp + rename）、自动建父目录、非空目录 `DELETE` 回 **409**、**越界回 403 而不是 404**、symlink-aware sanitization，以及明写「**无跨请求事务、无 CAS，协调责任在调用方**」——最后这条正是我们「文件面与 Task 无关、不占任务串行」在并发语义上的诚实说法。
- **「树在不在」应当是记录里可查的事实，不靠 `ls` 去猜**（借 Tekton 的 `$(workspaces.<name>.bound)` 形状）：冷档与热档的差别属于 Workspace 记录，文件面与 Task 都应能直接问。
