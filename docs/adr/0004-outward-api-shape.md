# 对外 API：OpenAPI 真源、两类凭据、长轮询

控制层的对外面（HTTP/JSON + OpenAPI + MCP，`#18`）有三条定形的选择，各自都容易被日后"顺手"改回去，因此写死在这里。**真源**：手写的 `api/openapi.yaml`（OpenAPI 3.1）是唯一真源，Go 侧与 MCP 工具的参数类型都由 `oapi-codegen` 生成——只有**给模型看的 prose**（工具 description、`--help` 的语义解释）手写。**凭据**：同一套 Bearer 方案分两类凭据——调用方持 `STARS_SANDBOX_TOKEN` 打 `/v1/`，运维持 `STARS_SANDBOX_ADMIN_TOKEN` 打 `/v1/admin/`；签发登记包等于**造出一个新的 Worker 身份**，是唯一能把一次凭据泄漏放大成仓库内容泄漏的路（ADR-0001 好不容易挡掉的那条），所以它绝不能与智能体揣着的那枚 token 同权。**观察**：对外只有长轮询（`?wait=`，服务端上限 60s，到点返回 200 + 当前快照），没有 SSE / WebSocket；且**非终态与失真照实外露**（`running`、日志的 `gapped` / `truncated`），但 `worker_id` / `machine_id` / 机队内情不进提交面的任何响应。

**Status**: accepted（`#18`）

## Considered Options

- **code-first 生成 OpenAPI**（`stars-auth` 那条血脉，`huma` 从 Go 类型运行时生成）：少一份要维护的文件，但 ADR-0002 的不变量（"一个操作一对一映射、参数同源、命名同源"）就失去了强制点——它只剩纪律，而纪律会在第一次赶工时破。
- **一个 surface、一枚 token**：最省事，但登记包签发、撤销 Worker 与提交任务同权，见上。
- **SSE / WebSocket 推送给调用方**：省往返，但要自造连接生命周期、重连与代理缓冲三套状态机；而 `#7` 已把重试权交给调用方，推送等于把重试重新藏回能力面。
- **每请求的版本闸门**（`stars-trail` 的 `X-Client-Version` + 426）：那是给"客户端装在别人机器上、我们改不动"的场景付的税。我们的客户端就是自己发布的那个二进制，一条命令就升级，所以只在**启动时**握手一次（`GET /v1/version`），不匹配当场大声失败。
- **`push` 发一张凭条**（异步 + 查 operation）：唯一理由是"客户端超时后不知道成没成"，而同 refspec 的重推天然幂等（非快进会**大声失败**，不会静默半成功），这个前提在这里不成立。
- **把任务失败映射成 HTTP 错误**：会让"我的脚本错了"与"被跑的命令错了"再也分不清——`#7` 把 `lost` 单列是同一个理由。
- **自写一个 OpenAPI → MCP 工具表的生成器**：那是一个要长期维护的编译器，只为省下十来个工具注册的胶水，而它的产物正是最该由人对着模型写的 prose。MCP 注册层因此手写，但入参类型复用生成物——"参数不能漂移"是编译期事实，不是 CI 纪律。

## Consequences

- **生成物必须进 CI**：`go generate ./...` 后有 diff 就红（照 `stars-trail` 的纪律）。MCP 侧的漂移因此只剩 prose 一种可能。
- **CLI 是全集 ≠ CLI 有全权**：管理子命令在只有调用方凭据时得到 `403`。全集说的是二进制里有那些命令，不是任何调用者都能用。
- **MCP server 只配调用方凭据**——ADR-0002 那句"与管理面共用同一套对外鉴权"说的是**方案同源，不是同权**，于是它无可救药地无害。
- 两个常数纪律要进 Skill 文档，否则 agent 会把正常等待读成失败：`wait` 的服务端上限 60s；推大仓前把 MCP 客户端超时调大。
- 长期凭据（Git 实例的铸造凭据）留在**部署期配置**里，Grant 的录入面因此可以是一枚普通鉴权下的普通 POST——请求体里没有任何秘密。
- 对外读模型是内部状态的**投影**，不是内部状态机本身：`assigned` / `acked` 不外露，`queued` 并入 `pending{workspace_busy}`（覆盖 `#9` 的措辞，内部派生不变）。同理 `artifact_get` 返回 URL 字段（**覆盖 `#14` 的 302**）。
